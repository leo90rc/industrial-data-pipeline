# Data Model

This document describes the data model used in the Industrial Data Pipeline project.

The model represents a simplified industrial environment where sensors collect operational measurements from different production units. These measurements are later used to detect abnormal operating conditions and calculate performance indicators.

---

## Entity Relationship Overview

```text
sensors
   │
   │ 1:N
   ▼
measurements
   │
   │ 1:N
   ▼
alerts
```

---

## Sensors

Sensor master data.

| Column            | Description               |
|-------------------|-------------------------- |
| sensor_id         | Unique sensor identifier  |
| sensor_name       | Sensor tag                |
| production_unit   | Production area           |
| variable_type     | Measured variable         |
| engineering_unit  | Measurement unit          |
| min_limit         | Lower operating limit     |
| max_limit         | Upper operating limit     |

## Measurements

Time-series measurements generated by sensors.

| Column         | Description                           |
| -------------- | ------------------------------------- |
| measurement_id | Unique measurement identifier         |
| sensor_id      | Sensor that generated the measurement |
| timestamp      | Date and time of the measurement      |
| value          | Recorded measurement value            |


## Alerts

Operational alerts generated when limits are exceeded.

| Column         | Description                          |
| -------------- | ------------------------------------ |
| alert_id       | Unique alert identifier              |
| measurement_id | Measurement that triggered the alert |
| alert_type     | Type of alert generated              |
| severity       | Alert severity level                 |
| created_at     | Alert creation timestamp             |

---

## Design Notes

The model separates sensor metadata from measurement records. This avoids repeating sensor information in every measurement and makes the structure easier to maintain.

The alerts table is derived from measurements and allows abnormal operating conditions to be analyzed separately from normal sensor readings.
